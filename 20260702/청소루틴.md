

# 🏠 4인 가족 집 전체 리셋 체크리스트

✔️ 아래 번호는 날짜가 아니라, 시간날 때마다 하나씩 체크하는 용도입니다. 언제 끝내야 한다는 부담 없이, 여유 있을 때마다 한 칸씩 진행해 주세요!

원칙 : 하루 40~60분만 / 무리 금지 / "꺼내기 → 버리기 → 닦기 → 넣기"

- 주방: 수세미·행주 주 1회 교체, 서랍은 분류함 활용
