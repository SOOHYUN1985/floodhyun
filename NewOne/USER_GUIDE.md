# 사용자 가이드 (완전 초보자용)

이 문서는 프로그래밍이나 주식 분석을 전혀 몰라도 이 프로그램을 이해하고
사용할 수 있도록 만든 안내서입니다. **순서대로 따라 하기만 하면 됩니다.**

---

## 0. 이 프로그램이 하는 일 (한 문장)

> "지금 코스피·코스닥 시장이 어떤 상태인지 판단하고, **과거 20년 중 지금과 가장
> 비슷했던 날들을 찾아**, 그때 이후 시장이 실제로 어떻게 움직였는지를 근거로
> **지금 주식을 몇 % 들고 있는 게 합리적인지**를 알려주는 프로그램"

핵심은 "예언"이 아니라 **"과거 통계에 근거한 확률과 위험"** 을 보여주는 것입니다.
프로그램은 "무조건 오른다/내린다"고 말하지 않고, 항상 **확률·기대수익·위험·표본 수**를
함께 제시합니다.

## 1. 실행 방법 — 이것만 하면 됩니다

### 가장 쉬운 방법 (권장)

1. 파일 탐색기에서 `C:\FREE\gitTest\NewOne` 폴더를 엽니다.
2. **`run_report.bat` 파일을 더블클릭**합니다.
3. 검은 창이 뜨고 자동으로 아래 3단계가 진행됩니다.
   - ① 최신 시세 데이터 다운로드 (1~2분, 인터넷 필요)
   - ② 시장 분석 + 유사구간 검색 + 백테스트 (약 30초)
   - ③ 결과 리포트(HTML)가 웹브라우저에 자동으로 열림
4. 브라우저에 뜬 리포트를 읽으면 끝입니다.

결과 파일은 `results\날짜\` 폴더 안에 저장됩니다(HTML·Markdown·Excel).

> 창이 자동으로 닫히지 않고 "계속하려면 아무 키나 누르십시오"가 뜨면
> 리포트 확인 후 아무 키나 누르면 됩니다.

## 3. 리포트 읽는 법 (무엇이 나오나요?)

리포트는 크게 4부분입니다.

### (1) 시장 대시보드
코스피·코스닥 각각의 **국면**(상승장/횡보/하락장 등), 추세, 외국인·기관 수급,
RSI, 이격도, MDD(고점 대비 하락률)를 한눈에 보여줍니다.

### (2) 과거 유사구간 & 향후 통계
지금과 가장 비슷했던 **과거의 실제 날짜들**과, 그날 이후
1·3·5·10·20·60·120일 뒤 **평균 수익률·상승확률·최대 하락폭**을 표로 보여줍니다.
"상승/하락을 가른 변수"도 분석해, 비슷한 상황에서 무엇이 결과를 갈랐는지 알려줍니다.

### (3) Walk-forward 백테스트
과거에 이 방식대로 투자했다면 어떤 성과였는지 검증한 결과입니다(자세히는 5·6장).

### (4) 종합 해석 & 권장 주식비중
모든 것을 종합한 **권장 주식비중(%)** 과 사람이 읽을 수 있는 설명이 나옵니다.

### (5) 부록 — 클릭하면 펼쳐지는 쉬운 설명
리포트 맨 아래에 **부록**이 있습니다.
- 본문에서 **밑줄 친 어려운 용어**(워크포워드·부트스트랩·Sharpe 등)를 클릭하면
  부록의 쉬운 설명으로 자동 이동하며 그 항목이 펼쳐집니다.
- 부록 A: **"왜 이 주식비중이 나왔는지"** 시장별 계산 과정(방향·기대수익·위험·신뢰도→최종비중)
- 부록 B: **용어 사전** — 주식 초보자도 이해할 수 있는 24개 용어 풀이
- 차트: 유사구간 분위수 밴드 + **개별 유사사례 60일 경로**(빨강=상승/파랑=하락)

> **항상 표본 수(N)와 신뢰도를 같이 보세요.** N이 작으면(예: 5개 이하)
> 그 통계는 우연일 수 있어 프로그램이 비중을 중립(50%) 쪽으로 낮춥니다.

## 4. "워크포워드(Walk-forward)"가 무엇인가요?

한마디로 **"그 시점에 실제로 알 수 있었던 정보만으로, 매번 새로 판단해서,
그 판단을 이후 실제 시장에 적용해 성과를 쌓아가는 정직한 검증법"** 입니다.

### 왜 필요한가요? (핵심)
가장 흔한 실수는 **미래를 몰래 훔쳐보는 것(Look-ahead Bias)** 입니다.
예를 들어 "2015년 1월 10일" 판단을 하면서 1월 11일 이후 데이터를 쓰면,
답을 이미 알고 문제를 푸는 셈이라 백테스트 성적은 좋아 보여도
실제로는 전혀 통하지 않습니다.

### 이 프로그램은 이렇게 합니다
- 리밸런싱(비중 재조정) 시점 **t 마다** → **t 이전 데이터만으로** 유사구간을 찾고,
  통계를 내고, 비중을 정합니다.
- 그 비중을 **t 이후 실제 시장 수익률**에 적용합니다.
- 다음 시점으로 넘어가 이 과정을 계속 반복합니다.
- 데이터 표준화(스케일링) 통계조차 t 이전 값만 사용합니다.

즉, 각 시점은 **독립적인 "실전 모의고사"** 이고, 전체는 그 모의고사를
700번 넘게 반복한 결과입니다. 그래서 "과거에만 잘 맞는 착시"를 걸러냅니다.

비유하자면, 시험 문제를 풀 때 **뒷장의 정답을 절대 보지 않고**
그날까지 배운 것만으로 매번 새로 푸는 것과 같습니다.

## 5. "권장 주식비중"은 어떻게 나온 건가요?

단순히 "상승확률 70% → 주식 70%" 처럼 계산하지 **않습니다.**
아래 **4가지 요소를 따로 계산**한 뒤 합칩니다.

| 요소 | 의미 | 계산 방식(요약) |
|---|---|---|
| **Direction(방향)** | 오를 확률 | 5·10·20·60일 상승확률의 가중 평균 |
| **Expected Return(기대수익)** | 얼마나 오를까 | 20일 뒤 수익률의 **중앙값**(이상치에 강건) |
| **Risk(위험)** | 얼마나 빠질 수 있나 | 하위 10% 수익률과 경로상 최대낙폭(MAE) 중 큰 값 |
| **Confidence(신뢰도)** | 이 판단이 얼마나 믿을 만한가 | 표본 수 N + 방향 일관성 + 분포 산포 |

이 값들을 0~100점으로 바꿔 합성합니다.

```
방향점수   = 상승확률
수익점수   = 50 + 50 × tanh(기대수익 / 5)
위험점수   = 50 + 50 × tanh( 기대수익 / (위험회피계수 × 위험) )
종합점수   = 0.45×방향 + 0.30×수익 + 0.25×위험
권장비중   = 50 + (종합점수 − 50) × (신뢰도/100) × 성향계수   → 0~100%로 제한
```

### 가장 중요한 안전장치 두 가지
1. **신뢰도가 낮으면 비중이 50%(중립)로 수축합니다.**
   표본이 부족하거나 신호가 애매하면 "잘 모르겠으니 중간만 가자"가 됩니다.
   → 데이터보다 강한 확신을 갖지 않도록 설계했습니다.
2. **히스테리시스**: 비중 변화가 ±10% 미만이면 무시합니다.
   → "70% → 71% → 70%" 처럼 쓸데없이 자주 매매하는 것을 막습니다.

### 투자성향 3종
같은 통계라도 성향에 따라 배분 기준이 다릅니다.
- **공격형**: 수익(CAGR) 최대화 지향 (위험을 더 감수)
- **균형형**: 위험 대비 수익(Sharpe) 균형 — **리포트의 기본 권장값**
- **안정형**: 낙폭(MDD) 최소화 지향 (보수적)

## 6. 백테스트는 몇 번, 어떻게 수행되나요?

### 규모 (실제 값은 리포트에 표시됨)
- 기간: **2012년 ~ 현재**, **5거래일(약 1주)마다** 비중을 재조정
  → 약 **700여 회의 의사결정 시점**
- 각 시점 × 2개 시장(코스피·코스닥) = **약 1,400회의 유사구간 검색**
  (검색 1회는 그 시점 과거 전체와 비교하는 작업)
- 한 번의 실행에서 **서로 다른 58종의 시뮬레이션**을 동시에 수행

### 58종 시뮬레이션 구성
| 분류 | 내용 |
|---|---|
| 투자성향 3종 | 공격형 / 균형형 / 안정형 (목적함수·위험회피 차이) |
| 단순 baseline 1종 | 상승확률만으로 비중 결정 (4요소 모델이 실제로 더 나은지 비교용) |
| 벤치마크 5종 | 코스피 B&H / 코스닥 B&H / 50:50 / 현금100% / MA200 추세추종 |
| 파라미터 민감도 3종 | 유사사례 수 K=20/40/60 (특정 숫자에 의존하지 않는지 확인) |
| 거래비용 민감도 4종 | 회당 비용 0 / 0.1 / 0.2 / 0.3% (실거래 비용에도 견디는지) |
| 이격도 그리드 42종 | 이동평균 7종(MA20/40/60/90/120/150/200) × 이격도 임계값 6종(105~130) (과열 회피 노출 전략, CAGR·Sharpe 매트릭스로 표시) |

### 추가 검증
- **연도별 성과**: 균형형 vs 코스피를 연도별로 비교 (특정 해에만 잘한 건 아닌지)
- **부트스트랩 신뢰구간**: 과거 수익을 1,000번 재배열해 CAGR·MDD의 5~95% 범위 추정
  (미래 경로 순서가 달라도 성과가 이 정도 범위일 수 있음을 보여줌)
- **국면별 성과 분해**: 코스피가 MA200 위(추세장)일 때와 아래(역추세장)일 때를
  나눠 각각의 성과를 확인
- 각 전략마다 지표: 총수익·CAGR·변동성·Sharpe·Sortino·MDD·Calmar·승률 + 자산곡선 차트

### 어떤 지표가 사용되나요?
백테스트의 핵심(유사구간 검색)은 아래 **13가지 지표를 한 꺼번에 조합**해 ‘지금과 비슷한 날’을 찾습니다:
- 수익률(5·20·60일), **이격도(20·60·120일)**, RSI(14), MACD 히스토그램,
  변동성(20일), MDD(120일), 거래량비, 외국인·기관 수급(20일 z)
- 이중 **이격도는 3개(20/60/120일)나 들어가** 이미 가장 비중 있게 쓰입니다.
- 게다가 위 ‘이격도 그리드 12종’은 이격도만으로 만든 독립 전략으로 따로 검증합니다.

### 왜 이렇게 여러 개를 돌리나요?
백테스트가 **하나만** 좋으면 "우연"일 수 있습니다.
성향·파라미터·거래비용·시장국면을 **폭넓게 바꿔도 성과가 유지되는지**를 봐야
"과거에만 맞는 요행"이 아니라 **견고한 전략**임을 확인할 수 있습니다.

### 어떻게 효율화했나요?
가장 비싼 작업(유사구간 검색)은 (시점, 시장)마다 **딱 1회만** 수행하고,
그 결과를 재사용해 58종을 값싸게 파생합니다. 그래서 전체가 약 40초에 끝납니다.

## 8. 자주 묻는 질문 (FAQ) & 문제 해결

**Q. 이 프로그램만 믿고 투자해도 되나요?**
A. 아니요. 이것은 **과거 통계에 근거한 참고 자료**입니다. 미래 수익을 보장하지
않습니다. 항상 확률·위험·표본 수를 함께 보고 본인 판단에 활용하세요.

**Q. "Excel 생성 실패: No module named 'openpyxl'" 이 떠요.**
A. 문제 아닙니다. HTML·Markdown 리포트는 정상 생성됩니다. Excel까지 원하면
`pip install openpyxl` 후 다시 실행하세요.

**Q. 외국인/기관 수급이 최신이 아니에요.**
A. 수급 자동 갱신에는 `pykrx` 가 필요합니다. `pip install pykrx` 후 실행하면
수급까지 최신화됩니다. 없으면 시세(가격)만 갱신됩니다.

**Q. 리포트의 날짜(기준일)가 오늘이 아니에요.**
A. 시세와 수급의 최신일이 다를 수 있어, **두 시장 모두 데이터가 완비된 마지막
날짜**로 자동 정렬합니다(미래 훔쳐보기·결측 방지). 정상 동작입니다.

**Q. 검은 창에 한글이 깨져 보여요.**
A. 콘솔 글꼴 문제일 뿐 결과에는 영향이 없습니다. 최종 리포트(HTML)는 정상입니다.

**Q. `python` 을 못 찾는다고 나와요.**
A. Python이 설치되지 않았거나 PATH에 없습니다. 2장을 참고해 설치하세요.

**Q. 인터넷이 안 되면요?**
A. 데이터 업데이트만 실패하고, 기존에 저장된 DB로 분석은 계속 진행됩니다.

## 9. 결과 파일 위치

```
NewOne/
├─ run_report.bat        ← 더블클릭해서 실행
├─ results/
│  ├─ latest_report.txt  ← 가장 최근 HTML 경로
│  ├─ 20260827_095626/  ← 기준일_실행시각(HHMMSS) 폴더 (하루에 여러 번 실행해도 안 섞임)
│  │  ├─ 시장비중리포트_20260827.html   ← 브라우저로 보는 리포트(부록·차트 포함)
│  │  ├─ 시장비중리포트_20260827.md     ← 텍스트(Markdown) 리포트
│  │  ├─ path_KOSPI.png / cases_KOSPI.png  ← 유사구간 및 개별사례 차트
│  │  └─ (openpyxl 설치 시) .xlsx       ← Excel 리포트
└─ data/                 ← 시세·수급 데이터베이스(자동 관리)
```

> 폴더 이름에 **실행 시각까지** 들어가므로, 같은 날 여러 번 실행해도
> 이전 리포트가 덮어써지지 않고 각각 따로 보관됩니다.
