# KOSPI·KOSDAQ 20년 데이터를 활용한 시장예측 및 적정 주식비중 산출 백테스트 시스템 구축

나는 약 20년간의 KOSPI와 KOSDAQ 일봉 데이터를 보유하고 있다.

보유 데이터에는 가격, 거래량, 외국인 수급, 기관 수급 등의 데이터가 포함되어 있다.

이 데이터를 활용하여 단순한 기술적 분석 프로그램이 아니라,

**현재 시장이 어떤 국면에 있는지 판단하고, 과거 20년 동안 현재와 가장 유사했던 시장 상황을 찾아낸 뒤, 그 유사 상황 이후 실제 시장이 어떻게 움직였는지를 통계적으로 분석하여 향후 시장의 상승·하락 가능성과 위험을 추정하고, 최종적으로 현재의 적정 주식비중까지 산출하는 백테스트 시스템**

을 Python으로 구축하고 싶다.

---

# 1. 프로젝트의 최종 목적

최종적으로 프로그램을 실행하면 다음 질문에 답할 수 있어야 한다.

1. 현재 KOSPI는 상승장인가 하락장인가?
2. 현재 KOSDAQ은 상승장인가 하락장인가?
3. 두 시장 중 어느 시장이 상대적으로 강한가?
4. 현재 외국인과 기관은 시장을 매수하고 있는가 매도하고 있는가?
5. 현재 시장은 과열인가 침체인가?
6. 현재 시장의 추세는 상승/하락 중 어느 방향인가?
7. 현재 시장의 변동성과 MDD는 어느 정도인가?
8. 현재 시장과 과거 20년 중 가장 비슷했던 시기는 언제인가?
9. 그 유사 시점 이후 실제 시장은 어떻게 움직였는가?
10. 현재와 유사한 상황에서 향후 1일, 3일, 5일, 10일, 20일, 1개월, 2개월, 3개월 후 평균적으로 어떻게 되었는가?
11. 각각의 기간에서 상승할 확률은 얼마였는가?
12. 그때 최대 상승폭과 최대 하락폭은 얼마였는가?
13. 현재 상황에서 기대수익률과 위험은 어느 정도인가?
14. 이러한 분석의 신뢰도는 어느 정도인가?
15. 이러한 결과를 종합했을 때 현재 주식비중을 몇 % 가져가는 것이 과거 데이터상 합리적인가?

# 2. 가장 중요한 원칙 — Look-ahead Bias 완전 차단

이 프로젝트에서 가장 중요한 원칙이다.

**미래 데이터를 과거 판단에 절대로 사용하지 마라.**

예를 들어 2015년 1월 10일의 시장 상태를 분석할 때 사용할 수 있는 데이터는 2015년 1월 10일까지 존재했던 데이터뿐이다.

2015년 1월 11일 이후의 데이터는 해당 날짜의 시장상태를 판단하는 데 절대로 사용해서는 안 된다.

각 날짜 t에서 사용할 수 있는 데이터는:

* t일까지의 가격
* t일까지의 거래량
* t일까지의 외국인 수급
* t일까지의 기관 수급
* t일까지 계산 가능한 기술적 지표
* t일까지 계산 가능한 MDD
* t일까지 계산 가능한 변동성
* t일까지 계산 가능한 모든 Feature

뿐이다.

그리고

* t+1
* t+3
* t+5
* t+10
* t+20
* t+60
* t+120

등의 미래 데이터는 오직 **사후 성과 평가용**으로만 사용한다.

특히 다음과 같은 실수를 절대로 하지 마라.

* 전체 기간을 대상으로 StandardScaler를 먼저 fit한 후 과거 데이터를 변환
* 미래 데이터를 포함하여 최적 RSI 값을 결정
* 미래의 수익률을 Feature에 포함
* 랜덤 Train/Test Split
* 전체 데이터를 이용한 Feature Selection 후 과거 Backtest
* 미래 데이터를 이용한 Threshold 최적화

모든 학습, Scaling, Feature Selection, Parameter Optimization은 반드시 해당 시점 이전의 데이터만 사용하도록 한다.

# 17. 유사도 계산

가능한 방법을 비교하라.

* Standardized Euclidean Distance
* Cosine Similarity
* Correlation Similarity
* Mahalanobis Distance
* KNN

가능하다면 여러 방법을 테스트하여 실제 미래 수익률 예측력이 가장 안정적인 방법을 선택한다.

단, 복잡한 방법을 사용하는 것 자체가 목적이 아니다.

**Out-of-Sample에서 실제로 잘 작동하는 방법을 선택하라.**

---

# 18. Feature Scaling

Feature마다 단위가 다르므로 적절한 Scaling을 적용한다.

검토:

* Z-score
* Robust Scaling
* Percentile Rank

특히 수급 데이터는 장기적으로 시장 규모가 변하기 때문에 절대금액보다 상대적인 수급을 적극 활용한다.

그리고 Scaling도 반드시 과거 데이터만 이용하여 Fit해야 한다.

---

# 19. 유사 날짜 중복 방지

예를 들어:

2020-03-10
2020-03-11
2020-03-12

가 모두 유사 날짜로 선택되면 사실상 같은 시장 상황을 3번 사용하는 문제가 발생한다.

따라서 유사 날짜를 선택할 때:

**최소 20거래일 또는 적절한 기간 이상 떨어진 날짜만 선택하는 방법**

을 검토한다.

또한 특정 하나의 시장 이벤트에 유사 사례가 몰리는 문제를 방지하라.

가능하다면 유사 사례를 Cluster로 묶어 대표 사례를 선택한다.

# 22. 평균만 보지 말 것

평균수익률 하나만으로 판단하지 마라.

반드시 분포를 확인한다.

예를 들어:

평균 +5%

라고 하더라도

* 대부분 +2~+5%였는지
* 일부 +50% 때문에 평균이 올라간 것인지
* 손실이 발생한 경우 얼마나 크게 손실이 났는지

확인해야 한다.

가능하면:

* Histogram
* Boxplot
* CDF
* Percentile

등으로 분포를 보여줘라.

Day 0 = 100

Day 1 = ...
Day 2 = ...
...
Day 120 = ...

그리고:

* 평균 경로
* 중앙값 경로
* 상위 25%
* 하위 25%
* 최대 상승 경로
* 최대 하락 경로

를 보여준다.

가능하면 25~75% 구간과 5~95% 구간도 표시한다.

# 24. Maximum Favorable / Adverse Excursion

최종 수익률만 보면 위험을 알 수 없다.

예를 들어 20일 후 +5%가 되었더라도 중간에 -10%까지 떨어졌을 수 있다.

따라서 각각의 유사 사례에 대해:

### MFE

Maximum Favorable Excursion

### MAE

Maximum Adverse Excursion

을 계산한다.

즉:

"이 상황에서 이후 최대로 얼마까지 올랐는가?"

"최종적으로 올랐더라도 중간에 얼마까지 떨어졌는가?"

를 분석한다.

이 결과를 주식비중 결정에 활용한다.

---

# 25. 조건부 분석

단순 유사도 분석 외에 중요한 조건들의 조합도 분석한다.

예:

RSI < 30

* 외국인 20일 순매수

* MDD -15%

* MACD 골든크로스

이런 상황 이후 수익률을 분석한다.

반대로:

RSI > 70

* 이격도 > 110

* 외국인 순매도

* 거래량 급증

등의 과열 조건도 분석한다.

단, 조건을 지나치게 많이 조합해서 과적합하지 마라.

충분한 표본 수가 있는 조건만 사용한다.

# 26. "상승/하락을 가른 변수" 분석

이 부분을 매우 중요하게 분석하라.

현재와 비슷한 과거 사례가 100개 있다고 가정한다.

그중:

* 70개는 이후 상승
* 30개는 이후 하락

했다면,

**상승한 70개와 하락한 30개의 차이가 무엇이었는지 찾아라.**

예를 들어:

상승 사례:

* 외국인 20일 수급 강함
* RSI 50~65
* 이격도 102~106
* MDD -3~-7%
* MACD 상승

하락 사례:

* 외국인 수급 약함
* RSI 70 이상
* 이격도 110 이상
* 거래량 급증
* MACD 둔화

등의 차이를 찾아라.

즉,

**"현재와 비슷한 과거 사례는 무엇이었는가?"**

뿐 아니라

**"그 유사 사례 중 어떤 경우에 상승했고 어떤 경우에 하락했는가?"**

를 분석해야 한다.

# 29. 주식비중 결정 모델

이 프로젝트의 최종 목적은 **현재 적정 주식비중 산출**이다.

단순히:

"상승확률 70% → 주식 70%"

와 같이 계산하지 마라.

최소한 다음 4가지 요소를 분리해서 계산하라.

## Direction

향후 상승할 확률

## Expected Return

기대수익률

## Risk

예상 최대 하락폭 / 변동성 / MDD

## Confidence

해당 판단의 통계적 신뢰도

예:

Direction = 75

Expected Return = +6.5%

Risk = -4.2%

Confidence = 82

등의 구조다.

# 30. 주식비중 모델

최종적으로 다음 중 하나의 방법을 선택하거나 여러 방법을 비교하라.

### 방법 A

Rule-based Score

### 방법 B

통계 기반 Expected Utility

### 방법 C

Risk-adjusted Exposure

### 방법 D

Machine Learning

### 방법 E

위 방법들을 조합

단, 어떤 방법이 가장 좋은지는 과거 데이터의 Out-of-Sample 성과로 판단한다.

# 31. 주식비중의 범위

최종적으로:

* 0~20%
* 20~40%
* 40~60%
* 60~80%
* 80~100%

또는 연속값:

* 35%
* 57%
* 73%
* 88%

등으로 결정할 수 있도록 한다.

하지만 실제 모델이 과도하게 잦은 매매를 유발하지 않도록:

* 최소 유지기간
* 비중 변경 Threshold
* 최대 일일 변경폭

등도 검토한다.

예를 들어:

현재 70%

→ 다음날 71%

처럼 작은 변화가 계속 발생하지 않도록 한다.

# 32. 주식비중 모델의 목적함수

단순히 수익률을 최대화하지 마라.

다음과 같은 목표를 비교한다.

### 공격형

CAGR 최대화

### 균형형

Sharpe Ratio 최대화

### 안정형

MDD 최소화 + 위험조정수익률 최대화

각 모델의 결과를 비교하고 어떤 모델이 장기간 안정적인지 분석한다.

**넓은 범위에서 성과가 안정적으로 유지되는지를 확인하는 것이 목적이다.**

## 58.3 Walk-forward(워크포워드)란

"그 시점에 실제로 알 수 있었던 데이터만으로 매번 새로 판단하고, 그 판단을
이후 실제 시장에 적용해 성과를 누적"하는 반복 검증 방식이다.

- 리밸런싱 시점 t 마다: t 이전 데이터로만 유사구간→통계→비중을 산출한다.
- 그 비중을 t~다음 리밸런싱 구간의 실제 시장수익률에 적용한다.
- 미래 데이터는 절대 사용하지 않는다(표준화 통계도 t 이전만 사용).
- 따라서 각 시점은 독립적인 Out-of-Sample 테스트이며, 전체는 그 반복이다.
- 랜덤 Train/Test Split(금융에서 미래누수 발생)을 사용하지 않는다.

## 58.4 권장 주식비중 산출 방법

단순히 "상승확률=비중"으로 하지 않고 4요소를 분리 계산한다.

1. Direction(방향): 여러 구간(5·10·20·60일) 상승확률의 가중 평균
2. Expected Return(기대수익): 20일 Forward 수익률의 **중앙값**(이상치에 강건)
3. Risk(위험): 하위 10%(p10) 수익률과 경로상 최대낙폭(MAE)의 큰 쪽
4. Confidence(신뢰도): 표본 수 N + 방향 일관성 + 분포 산포로 산출

이를 점수화하여 위험조정 노출로 합성한다:
- direction_score = 방향확률
- return_score = 50 + 50·tanh(기대수익/5)
- risk_score = 50 + 50·tanh( 기대수익 / (위험회피계수 × 위험) )
- composite = 0.45·direction + 0.30·return + 0.25·risk
- weight = 50 + (composite−50) × (신뢰도/100) × 성향tilt  → 0~100%로 클리핑

핵심: **신뢰도가 낮으면(표본 부족 등) 비중이 중립(50%) 쪽으로 수축**하여
데이터보다 강한 확신을 갖지 않는다. 히스테리시스(±10% 미만 변화 무시)로
잦은 매매를 억제한다.

  - **연도별 성과**(균형형 vs 코스피) — 국면별 강약 확인
